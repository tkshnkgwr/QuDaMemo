## 1. API キーの機密性と完全ローカル保護

- **ローカル限定保持**: ユーザーが設定した Gemini API キーは、ローカルマシン上の物理設定ファイル（`%USERPROFILE%\Documents\QuDaMemo\config.json`）およびアプリ実行中のメモリ内でのみ保持されます。
- **テレメトリ・トラッキング完全排除**: アプリケーション内にいかなる利用状況収集、トラッキング、アナリティクス、またはサードパーティ分析コードも含まれていません。
- **暗号化直接通信 (HTTPS)**: AI要約リクエストは、Google 公式の Gemini API エンドポイント（またはユーザーが自前で指定した中継プロキシ URL）との間でのみ暗号化通信（HTTPS）されます。

## 2. ローカルファイルシステムの保護とサンドボックス

- **Tauri v2 Capabilities 権限制御**:
  - `src-tauri/capabilities/default.json` により、アプリのファイルシステム操作やダイアログ表示の権限を最小限に絞り込んでいます。
- **厳格なパス解決と走査防止**:
  - メモファイル読み書きは、ユーザーが指定した `storagePath`（例: `%USERPROFILE%\Documents\QuDaMemo\notes`）および設定ファイルパス配下のみを対象とします。
  - 相対パスによるディレクトリトラバーサル（`../` による不正脱出）を Rust バックエンド側で遮断・防御します。
- **アトミック書き込みによるファイル保護**:
  - メモ保存時は、一時ファイルへの書き込みと同期（Flush）が完全に成功した後にリネームを行うアトミック方式を採用。電源断や強制終了時のファイル破損リスクを極小化しています。
