## 1. APIキーの保護と機密性

- ユーザー固有の Gemini API キーは、ローカル設定ファイル（`config.json`）およびメモリ内でのみ保持されます。
- 外部サードパーティサーバーやテレメトリ収集エンドポイントへ送信・漏洩することは一切ありません。
- リクエストは直接 Google Gemini 公式エンドポイント（またはユーザーが独自指定した中継プロキシ URL）との間でのみ暗号化（HTTPS）通信されます。

## 2. ローカルファイルアクセス制限

- Tauri v2 の権限システム（Capabilities）および Rust バックエンドのパス解決により、ユーザーが設定画面で指定した `storagePath` 配下および設定ファイルのみに対して読み書きを行います。
- 不正なパス走査（Path Traversal）や意図しないシステム領域への書き込みを防止します。
