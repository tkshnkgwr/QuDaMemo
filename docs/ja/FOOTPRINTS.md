## 3. CPU負荷 ＆ レンダリング最適化

- **インターバル制限 (1Hz Throttle)**: アイドル時の定期更新や時計・監視インターバルを 1 秒に 1 回 に抑制し、バックグラウンド CPU 使用率を **1% 未満** に維持。
- **Release Profile 最適化 (`Cargo.toml`)**:
  - `opt-level = 'z'`: バイナリサイズを最小化。
  - `lto = true`: 全クレート間のリンク時最適化。
  - `codegen-units = 1`: コード生成単位を1つにしてインライン展開と最適化を極大化。
  - `panic = 'abort'`: 不要なスタックアンワインドコードを削除。
  - `strip = true`: シンボルテーブルを削除してバイナリフットプリントを最小化。
