## 1. AI エージェント（大賢者）向け運用指針

本ドキュメントは、プロジェクトルートの [RULES.md](../../RULES.md) および [.agents/AGENTS.md](../../.agents/AGENTS.md) を補完する、AI エージェント向けの詳細開発・運用仕様書です。

### 1.1 対話・回答スタイル詳細

- **呼称と姿勢**: ボスのことは常に「ボス」とお呼びし、100%日本語で礼儀正しく迅速に対応します。
- **結論ファースト**: 冒頭で結論や対応サマリーを提示し、変更点や詳細ログを箇条書きで分かりやすく整理します。
- **ハイパーリンクの原則**: ファイルやコードシンボルを参照する際は、常に `[表示名](file:///絶対パス)` 形式（Windows パスは `/` スラッシュ統一）でクリッカブルリンクを生成します。
- **他言語経験者への配慮**: 専門用語は平易な一般的概念に置き換えて解説します（例: React Hooks は「状態変数とイベントライフタイムの監視ハンドラー」、Rust 所有権は「メモリの安全な貸し出しルール」など）。

### 1.2 高速 CLI ツールの標準利用原則

- **ソースコード・テキスト検索**: `grep` ではなく最速の **`ripgrep` (`rg`)** を最優先で使用。Git 管理下は `git grep` を活用。
- **ファイル・ディレクトリ探索**: `Get-ChildItem` や `find` ではなく **`fd`** を最優先で使用。
- **JSON 処理**: 設定や API 出力の抽出・整形には **`jq`** を優先活用。

## 3. ドキュメント自動同期ルール

機能追加・修正が発生した場合は、以下のドキュメントを同期更新します：

| ドキュメント       | 役割・対象領域                                                  | 更新タイミング                                 |
| :----------------- | :-------------------------------------------------------------- | :--------------------------------------------- |
| `CHANGELOG.md`     | バージョン別変更履歴 (日/英)                                    | 機能追加・修正・パフォーマンス改善・削除完了時 |
| `TODO.md`          | タスク進捗および今後の追加検討課題 (日/英)                      | タスク完了時、新機能アイデア起案時             |
| `SPECIFICATION.md` | 機能仕様・画面・データ構造・IPC (日/英)                         | 画面レイアウト・データ型・IPCコマンド変更時    |
| `ARCHITECTURE.md`  | システム境界・レイヤー・IPC・永続化フロー (日/英)               | プロセス構造・永続化設計・IPC通信の変更時      |
| `DEVELOPMENT.md`   | 開発環境・ディレクトリ構成・検証コマンド (日/英)                | ビルド手順・依存関係・開発コマンド変更時       |
| `README.md`        | プロジェクト概要・バッジ・クイックスタート (日/英)              | バージョン更新・主要機能追加・ライセンス変更時 |

## 4. バージョン管理規約 (Semantic Versioning)

修正の規模に応じて、以下の各ファイルのバージョン番号を統一更新します：
1. `package.json`
2. `src-tauri/Cargo.toml`
3. `src-tauri/tauri.conf.json`（`"version": "../package.json"` で自動参照）
4. `docs/ja/CHANGELOG.md` および `docs/en/CHANGELOG.md`
