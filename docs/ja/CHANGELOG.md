## [1.0.8] - 2026-08-07

### 追加 ＆ 改善 (Added & Improved)
- **設定ファイル (`config.json`) の物理保存・復元・同期**:
  - `AppSettings` をブラウザ LocalStorage だけでなく、アプリと同階層の `./config.json`（および指定保存先フォルダ）へ物理ファイルとして保存・読み込み同期する機能を導入。
- **YAML フロントマターへの `updated_at` 自動更新記録**:
  - メモ作成・編集・AI要約実行時に `updated_at` を標準YAMLフロントマターへ自動記録。エディタヘッダーに非編集の「更新日時」バッジとして表示。
- **カレンダー機能 ＆ カスタム祝日管理**:
  - 日本の祝日情報の外部ファイル化、および設定画面からユーザーが任意のカスタム祝日を登録・削除できる機能を追加。
  - 週カレンダーでのホバーツールチップ表示位置をマウスカーソル近傍 (`e.clientX`, `e.clientY`) へ動的追従改善。
- **画面遷移状態の維持（カレンダーへの自動復帰）**:
  - 月カレンダー・週カレンダー・通常一覧のどの画面からメモ編集を開いても、「閉じる＆一覧へ」をクリックした際は元いた画面へ正確に復帰する状態記憶ロジックを追加。
  - 検索日付範囲のデフォルト初期値を「当月1日〜末日」にセット。
- **アプリ概要 ＆ 使い方ガイドモーダルの独立**:
  - 「アプリの概要・使い方ガイド」を独自モーダル (`AppOverviewModal`) として新設。キーボードショートカット確認 (`KeyboardShortcutsModal`) を純粋なキー一覧専用画面に分離。
- **UI スタイル・スクロールバーのダークモード対応**:
  - 全一覧およびコンポーネントのスクロールバーをダークモード仕様 (`color-scheme: dark`, `::-webkit-scrollbar`) に調整。
  - 設定画面のキャッシュクリア時に「物理 `.md` ファイルは削除されない」旨の注意事項カードを明記。
- **CI / Release ワークフロー構成**:
  - GitHub CI / Release ワークフロー (`ci.yml`, `release.yml`) を整備・最適化。

## [1.0.2] - 2026-08-05

### 追加 ＆ 改善 (Added & Improved)
- **二重起動の完全禁止 (Single Instance)**:
  - `tauri-plugin-single-instance` を導入し、重複起動を防止。2つ目が起動を試みた際は既存ウィンドウを前面化・フォーカス。
- **前回起動位置・サイズの全自動記憶 ＆ 復元**:
  - `tauri-plugin-window-state` を導入し、アプリ終了時のウィンドウ位置 (X, Y) やサイズ (幅, 高さ, 最大化状態) を次回起動時に完璧復元。
- **タイトルバー (TitleBar) の表示整理・動的化**:
  - `package.json` からアプリバージョンを動的取得して表示 (`v1.0.2`)。
  - 「Rust Engine」バッジ、保存フォルダパス、Pos(ウィンドウ座標) 表示を削除して洗練されたUIへ変更。
  - ヘルプボタン（HelpCircle）を追加（QuMaEditor準拠）。F1 / Ctrl+? と連動してキーボードショートカット確認画面を開く。
- **設定モーダル (SettingsModal) のレイアウトガタつき解消**:
  - モーダル外枠を固定高 (`h-[580px]`) に統一し、左メニュー切り替え時の伸縮・レイアウトシフトを解消。

## [1.0.1] - 2026-08-05

### 修正 (Fixed)
- **物理.mdファイル保存エラーの根本修正**:
  - Rustの `FrontmatterDto` 構造体フィールド (`title` 等) に `#[serde(default)]` / `Option` を適用し、JSONデシリアライズ時の型不一致エラーを解決。
  - Tauri `capabilities/default.json` の `fs` パーミッションを拡充し、ユーザー指定フォルダへの安全な物理書き込みを許可。
  - `getOrCreateMemoForDate` 関数へ `settings` を正しく伝搬し、新規作成時のディスク保存が漏れないよう改修。
- **LocalStorage キャッシュの肥大化防止 ＆ 管理機能の導入**:
  - LocalStorage をUI表示用の一時キャッシュとして位置づけ、最大365件に自動トリムする処理を追加。
  - 設定画面「その他」タブに LocalStorage 物理格納先パス（`%LOCALAPPDATA%\...`）の明示表示を追加。
  - LocalStorage 一時キャッシュ全消去ボタンを設置（指定保存先の物理 `.md` ファイルは安全に保護）。

## [0.1.1] - 2026-08-03

### 追加 (Added)
- **Tauri Native HTTP プラグイン (`@tauri-apps/plugin-http`) による CORS バイパス**:
  - ブラウザの CORS / Origin 制約を受けることなく、中継プロキシやカスタム Base URL へ安全かつダイレクトにリクエスト送信を可能にするネイティブ通信モジュールを構築。
- **二重 AI 接続テスト & テスト結果の永続化・自動上書き**:
  - API要約接続テストおよび Web/URL エンドポイント接続テストの二重検証機能を実装。
  - テスト実行日時（タイムスタンプ）と結果を保存し、次回起動時も前回の結果を表示。再実行時は最新状態へ自動上書き。
- **2カラム型カテゴリ設定モーダル (SettingsModal)**:
  - 左メニュータブ（📂全般, 🤖AI・要約, 🎨テーマ, 📦その他）によるスッキリとした2カラム型設定画面へフルリファクタリング。
  - APIキー設定時のアクティブ表示ドット（緑色点滅）インジケーターを追加。
- **自動保存タイミングの可変カスタマイズ機能**:
  - 設定画面から自動保存タイマー（入力停止後の待機秒数）を変更可能に（デフォルト10秒、0秒不可）。
  - キー入力時の誤った「自動保存中...」表示バグを修復し、タイピング中「未保存」➔ 10秒経過「自動保存中...」➔「保存完了」の正常な状態遷移を徹底。
- **「閉じる＆一覧へ」の待ち時間 0 秒化 ＆ バックグラウンド非同期 AI 要約**:
  - ボタンクリック時、`await` 通信待機を行わず即座に一覧画面へ復帰。AI要約処理はバックグラウンドで非同期実行され、完了後に物理ファイルを全自動更新。
- **設定済みフォルダ優先のダイアログ起動**:
  - 「参照...」ボタンクリック時、前回開いた場所ではなく現在設定画面に入力されているローカルパス（例: `C:\Users\632792\Documents\QuDaMemo\notes`）を直接初期表示してダイアログを開くよう改善。
- **物理ファイル保存先 ＆ ログローテーションシステム**:
  - 実在するローカルパス `C:\Users\<ユーザー名>\Documents\QuDaMemo\notes` へデフォルト保存先を自動補正。
  - ログ出力先 `[storagePath]/logs/qudamemo.log` での 500KB 超過時 3世代（`qudamemo.log`, `qudamemo.log.1`, `qudamemo.log.2`）自動シフトローテーション機構。
