## [0.1.1] - 2026-08-03

### 追加 (Added)
- **Tauri Native HTTP プラグイン (`@tauri-apps/plugin-http`) による CORS バイパス**:
  - ブラウザの CORS / Origin 制約を受けることなく、中継プロキシやカスタム Base URL へ安全かつダイレクトにリクエスト送信を可能にするネイティブ通信モジュールを構築。
- **二重 AI 接続テスト & テスト結果の永続化・自動上書き**:
  - API要約接続テストおよび Web/URL エンドポイント接続テストの二重検証機能を実装。
  - テスト実行日時（タイムスタンプ）と結果を保存し、次回起動時も前回の結果を表示。再実行時は最新状態へ自動上書き。
- **2カラム型カテゴリ設定モーダル (SettingsModal)**:
  - 左メニュータブ（📂全般, 🤖AI・要約, 🎨テーマ, 📦その他）によるスッキリとした2カラム型設定画面へフルリファクタリング。
  - APIキー設定時のアクティブ表示ドット（緑色点滅）インジケーターを追加。
- **自動保存タイミングの可変カスタマイズ機能**:
  - 設定画面から自動保存タイマー（入力停止後の待機秒数）を変更可能に（デフォルト10秒、0秒不可）。
  - キー入力時の誤った「自動保存中...」表示バグを修復し、タイピング中「未保存」➔ 10秒経過「自動保存中...」➔「保存完了」の正常な状態遷移を徹底。
- **「閉じる＆一覧へ」の待ち時間 0 秒化 ＆ バックグラウンド非同期 AI 要約**:
  - ボタンクリック時、`await` 通信待機を行わず即座に一覧画面へ復帰。AI要約処理はバックグラウンドで非同期実行され、完了後に物理ファイルを全自動更新。
- **設定済みフォルダ優先のダイアログ起動**:
  - 「参照...」ボタンクリック時、前回開いた場所ではなく現在設定画面に入力されているローカルパス（例: `C:\Users\632792\Documents\QuDaMemo\notes`）を直接初期表示してダイアログを開くよう改善。
- **物理ファイル保存先 ＆ ログローテーションシステム**:
  - 実在するローカルパス `C:\Users\<ユーザー名>\Documents\QuDaMemo\notes` へデフォルト保存先を自動補正。
  - ログ出力先 `[storagePath]/logs/qudamemo.log` での 500KB 超過時 3世代（`qudamemo.log`, `qudamemo.log.1`, `qudamemo.log.2`）自動シフトローテーション機構。

## [0.1.0] - 2026-08-03

### 追加 (Added)
- **Tauri v2 デスクトップアプリ化**:
  - `src-tauri` バックエンド構造を新設。
  - 枠なし (`decorations: false`)・透過表示 (`transparent: true`)・影なし (`shadow: false`) のスタイリッシュなモダンデスクトップフレームワークの追加。
  - ウィンドウドラッグ移動 (`data-tauri-drag-region`) およびネイティブ制御ボタン（最小化・最大化・閉じる）の完全接続。
  - `@tauri-apps/plugin-dialog` によるネイティブ保存・フォルダ選択ダイアログの追加。
- **デフォルトAIモデルの標準化**: 設定画面のデフォルトAIモデルを `Google Gemini 3.6 Flash` (`gemini-3.6-flash`) に設定。
- **AI Agent ガイドライン最適化**: `.agents/AGENTS.md` の新規策定およびスリム化。
