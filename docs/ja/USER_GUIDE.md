## 1. QuDaMemo とは

QuDaMemo（Quick Daily Memo）は、日常の思考や作業ログをストレスなく記録するために設計された、超軽量かつ高速な Daily Markdown Memo デスクトップアプリです。
Windows の低スペック環境でも軽快に動作し、Obsidian 等の外部 Markdown エディタとシームレスに併用できます。

---

## 2. 基本機能と操作方法

### 2.1 メモの作成と編集

- **本日のメモを開く**:
  - タイトルバー右側の「今日のメモを作成」（ペンのアイコン）をクリックすると、本日の日付ファイル（例: `20261108.md`）が即座に開きます。
  - すでにメモが存在する場合は既存のメモを読み込み、存在しない場合は自動的に Frontmatter を付与して新規作成します。
- **カレンダーからの過去メモ選択**:
  - メイン画面の「月カレンダー」または「週カレンダー」で任意の日付をクリックすると、その日のデイリーメモを開いて編集できます。
  - 週カレンダーでは、日付カードにマウスをホバーするとその日のメモタイトルや要約がカーソル位置に追従してポップアップ表示されます。
- **エディタ操作**:
  - 標準的な Markdown 記法（見出し、箇条書き、チェックボックス `- [ ]`、コードブロック等）に対応。
  - メモ保存時はヘッダーの `updated_at` バッジが自動更新されます。
  - 「閉じる＆一覧へ」ボタンを押すと、編集内容をアトミック保存し、開く前にいた画面（月カレンダー/週カレンダー/通常一覧）へ正確に戻ります。

### 2.2 AI 要約機能 (Gemini)

- **要約の生成**:
  - エディタ下部またはツールバーの「AI要約生成」（星アイコン）をクリックすると、現在のメモ本文から要約を自動生成します。
  - **待ち時間ゼロの即時終了**: 要約生成中に「閉じる＆一覧へ」を押しても処理はキャンセルされず、バックグラウンド非同期処理として裏で完了・自動保存されます。
- **要約プロンプトのカスタマイズ**:
  - 設定画面の「AI・要約」タブにて、要約ルール（文字数、重視する観点、箇条書き形式等）を自由に指定可能です。

### 2.3 AI モデルの選定ガイド

日常のメモ要約には、最新の **`gemini-3.7-flash`** が最も高速・高精度でおすすめです。

| モデル                 | 速度/レスポンス | 要約品質       | 特徴と用途                                     |
| :--------------------- | :-------------- | :------------- | :--------------------------------------------- |
| **`gemini-3.7-flash`** | ⚡ 最速クラス   | ⭐⭐⭐⭐⭐ 最高 | **【標準・推奨】** 思考推論と爆速応答を両立    |
| **`gemini-2.0-flash`** | ⚡ 最速クラス   | ⭐⭐⭐⭐ 高     | 低レイテンシ特化の高速モデル                   |
| **`gemini-1.5-flash`** | 🟡 普通        | ⭐⭐⭐ 普通     | 旧世代。日常用途では 3.7 Flash が完全上位互換  |
| **`gemini-1.5-pro`**   | 🐢 やや遅い    | ⭐⭐⭐⭐ 高     | 200万トークン超長文や社内承認環境向け後方互換   |

※社内プロキシ等で特定モデルしか許可されていない場合や、今後登場する最新モデルを使用したい場合は、設定画面で「カスタム指定」を選び、モデル名を手動で直接入力できます。

## 3. 設定画面のカスタマイズ (SettingsModal)

タイトルバーの歯車アイコンをクリックすると、2カラム構成の設定モーダルが開きます。

1. 📂 **全般 (General)**:
   - **メモ保存先フォルダ**: デイリーメモ（`.md`）を保存するローカルフォルダを指定（例: `%USERPROFILE%\Documents\QuDaMemo\notes`）。
   - **ファイル命名ルール**: デフォルトは `YYYYMMDD`。
   - **Frontmatter テンプレート**: 新規作成時に自動挿入される YAML テンプレートの編集。
   - **自動保存インターバル**: 入力中の自動保存間隔秒数を指定（デフォルト 10 秒）。
2. 🤖 **AI・要約 (AI & Summary)**:
   - **Gemini API キー**: Google AI Studio で発行した API キーを設定。
   - **使用 AI モデル**: プリセット一覧からの選択、または手動カスタム入力。
   - **Base URL**: 社内プロキシやリバースプロキシ経由先のエンドポイント URL を指定可能。
   - **AI接続テスト**: API直通とプロキシ経由の疎通可否・レイテンシを二重検証。
3. 🎨 **テーマ (Theme)**:
   - **外観テーマ**: 「ダーク」「ライト」「OS設定に連動」から選択。
   - **カレンダー開始曜日**: 月曜始まり / 日曜始まり を切り替え。
4. 📅 **カスタム祝日 (Custom Holidays)**:
   - 日本の祝日に加え、会社創立記念日や個人的な記念日を日付と名称で登録可能。カレンダーに自動反映されます。
5. 📦 **バックアップ・その他 (Backup & Misc)**:
   - **設定のエクスポート / インポート**: `config.json` を安全に保存・移行。
   - **キャッシュ全削除**: WebView2 の一時データを初期化（物理メモ `.md` ファイルは一切削除されません）。

## 4. ヘルプ ＆ システム機能

タイトルバーの「？」アイコンをクリックすると、便利なユーティリティメニューが開きます。

- **キーボードショートカット (F1)**:
  - 主要な操作キーの一覧表を表示します。
- **アプリログの確認**:
  - `qudamemo.log` の内容をポップアップモーダル上でリアルタイム閲覧・コピー・クリアできます。
- **QuDaMemo について**:
  - 現在のバージョン、コア技術スタック、GPL-3.0-or-later ライセンスを確認できます。

---

## 5. Obsidian との連携 Tips

QuDaMemo の保存先フォルダ（例: `%USERPROFILE%\Documents\QuDaMemo\notes`）を、そのまま Obsidian の「Vault（保管庫）」として開くことができます。
これにより、日中は QuDaMemo で爆速メモ・AI要約を行い、後から Obsidian でグラフビューや詳細なノート整理を行うといったハイブリッドなワークフローが実現します。
