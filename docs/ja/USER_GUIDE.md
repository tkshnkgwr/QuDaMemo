# ユーザーガイド (USER_GUIDE.md) - QuDaMemo

[English Version](../en/USER_GUIDE.md) | **日本語版**

## 1. はじめに
QuDaMemoは、日々のメモ作成とAI要約を高速に行うためのデイリーメモアプリです。

## 2. 基本操作方法

### 2.1 メモの作成と編集

- サイドバーのカレンダーまたは「今日のメモを作成」ボタンをクリックすると、`YYYYMMDD.md` 形式でメモが開きます。
- マークダウン記法で自由にテキストを入力できます。

### 2.2 AI要約機能の使用

- メモ入力後、ツールバーの「AI要約生成」ボタン（星アイコン）をクリックします。
- 設定されたGeminiモデル（例: `gemini-3.7-flash`）が呼び出され、要約ルールに従って即座に本文の要約が生成・挿入されます。

### 2.3 設定のカスタマイズ

- 右上の歯車アイコン（設定）をクリックします。
- **使用AIモデル**: ドロップダウンから `gemini-3.7-flash (最新・推論＆爆速)`、`gemini-3.6-pro`、`gemini-2.5-pro` などの各種モデルを選択、または「カスタム指定」を選んで任意のモデル名（プレビュー版や社内プロキシ専用モデル等）を直接入力できます。
- **要約ルール**: AIに与える要約プロンプト（文字数や重視する項目）を自由にカスタマイズ可能です。

### 2.4 AIモデルの選び方（推奨モデルと旧世代モデルの違い）

日常のメモ要約には、最新の **`gemini-3.7-flash`** が最も高速・高精度でおすすめです。

| モデル                 | 速度/レスポンス | 要約品質       | 特徴と用途                                     |
| :--------------------- | :-------------- | :------------- | :--------------------------------------------- |
| **`gemini-3.7-flash`** | ⚡ 最速クラス   | ⭐⭐⭐⭐⭐ 最高 | **【標準・推奨】** 思考推論と爆速応答を両立    |
| **`gemini-2.0-flash`** | ⚡ 最速クラス   | ⭐⭐⭐⭐ 高     | 低レイテンシ特化の高速モデル                   |
| **`gemini-1.5-flash`** | 🟡 普通        | ⭐⭐⭐ 普通     | 旧世代。日常用途では 3.7 Flash が完全上位互換  |
| **`gemini-1.5-pro`**   | 🐢 やや遅い    | ⭐⭐⭐⭐ 高     | 200万トークン超長文や社内承認環境向け後方互換   |

※「1.5 系の方が速い」ということはなく、2.0 / 3.x 世代の方が圧倒的にレスポンスが高速です。社内プロキシで承認モデルが 1.5 系に固定されている場合等を除き、基本的に 3.7 Flash をご使用ください。
