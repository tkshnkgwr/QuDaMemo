# ユーザーガイド (USER_GUIDE.md) - QuDaMemo

## 1. はじめに
QuDaMemoは、日々のメモ作成とAI要約を高速に行うためのデイリーメモアプリです。

## 2. 基本操作方法
### 2.1 メモの作成と編集
- サイドバーのカレンダーまたは「今日のメモを作成」ボタンをクリックすると、`YYYYMMDD.md` 形式でメモが開きます。
- マークダウン記法で自由にテキストを入力できます。

### 2.2 AI要約機能の使用
- メモ入力後、ツールバーの「AI要約生成」ボタン（星アイコン）をクリックします。
- 設定されたGeminiモデル（例: `gemini-3.6-flash`）が呼び出され、要約ルールに従って即座に本文の要約が生成・挿入されます。

### 2.3 設定のカスタマイズ
- 右上の歯車アイコン（設定）をクリックします。
- **使用AIモデル**: リストボックスから `Google Gemini 3.6 Flash` など目的のモデルを選択します。
- **要約ルール**: AIに与える要約プロンプト（文字数や重視する項目）を自由にカスタマイズ可能です。
