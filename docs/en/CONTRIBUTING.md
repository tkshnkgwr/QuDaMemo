# Contribution Guidelines (CONTRIBUTING.md) - QuDaMemo

**English Version** | [日本語版](../ja/CONTRIBUTING.md)

## 1. Development Guidelines

1. **Avoid Breaking Changes**: Do not modify layouts, styles, or core behavior outside requested scope.
2. **Inline Annotations**: Tag modifications with `// UPDATE [YYYY-MM-DD]: [Reason]`.
3. **Bilingual Documentation**: Update both Japanese (`docs/ja/`) and English (`docs/en/`) documentation synchronously.

## 2. Commit Conventions

- `feat:` New features
- `fix:` Bug fixes
- `docs:` Documentation updates
- `refactor:` Code refactoring without behavior changes
